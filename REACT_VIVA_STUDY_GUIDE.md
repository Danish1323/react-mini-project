## How to Study

1. Read **Part 1** first. It explains the very basics — what React even is, what happens when you type `npm run dev`, what JSX means.
2. Then read **Part 2**. It explains how React "remembers" things (state) and how it talks to the backend (useEffect).
3. Then read **Part 3**. It explains how lists are drawn, how pages are routed, and how we styled the app.
4. Finally, go through **Part 4** — it has 50+ practice viva questions with model answers.

> **Important:** Every single code example in this guide is taken directly from YOUR InvenTrack project files. Nothing is made up.
